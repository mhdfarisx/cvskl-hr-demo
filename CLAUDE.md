# cvskl-hr-demo

Static HTML demo — CVSKL + PICASO full HR System. More comprehensive than cvskl-hiring-tracker. Single-page app. No backend, demo data only.

## Stack
- Vanilla HTML/CSS/JS (no framework)
- Chart.js 4.4.0 (CDN)
- Google Fonts — Inter
- `css/style.css`, `js/` — styles and logic

## Pages (sidebar nav)
- Dashboard — HR overview
- Staff List
- Movement Log
- Job Requisitions
- Pipeline Board
- All Candidates

## Key Facts
- Dual client: CVSKL + PICASO (both logos in sidebar)
- Powered by Syntrogic
- Demo persona: "Nur Aisyah, HR Manager"
- Superset of cvskl-hiring-tracker (adds staff management + movement log)
- Single `index.html` entry point
